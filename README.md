#Rock Paper Scissors Game
##About the Project 
This is a simple Rock Paper scissors game built using HTML, CSS , and JavaScript. The player plays against the computer.
##Technologies used:
-HTML
-CSS
-JavaScript
##Features
-Interactive gameplay
-Computer-generated choices
-Displays the game result
-Simple and user-friendly interface
